Banking Transaction Analysis

A Python project for analyzing banking transaction data stored in CSV files.

Project Overview

The application reads banking transaction data from a CSV file, performs several analyses, displays key results in the console, and automatically generates a CSV report.

Features

Calculate the total value of transactions

Calculate the average transaction value

Identify the largest transaction

Count high-value transactions

Calculate total transaction value per client

Identify the client with the highest transaction volume

Calculate totals by transaction type

Calculate totals by city

Identify the largest transfer

Calculate the percentage of high-value transactions

Count transactions per client

Export key results to a CSV report

Technologies

Python

CSV file processing

Dictionaries

Functions

Loops and conditional statements

Exception handling

Project Structure

main.py — runs the application and displays the analysis

analiza_tranzactii.py — contains the data analysis functions

tranzactii.csv — source dataset

raport_tranzactii.csv — automatically generated analysis report
